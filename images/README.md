## Características Técnicas

### Formato y Tamaño
- **Formato**: JPG (fotos) o PNG (gráficos)
- **Calidad**: 80-90% optimización
- **Tamaño máximo**: 500KB por imagen
- **Dimensiones**:
  - Hero: 1920x1080px (16:9)
  - Galería: 800x600px (4:3)
  - Servicios: 400x300px (4:3)
  - Og-image: 1200x630px

### Optimización
- Usar herramientas como TinyPNG o Squoosh
- Incluir alt text descriptivo
- Comprimir sin perder calidad visible

## Tips para Selección

1. **Calidad**: Siempre elegir imágenes de alta resolución
2. **Estilo**: Mantener coherencia visual en todo el sitio
3. **Iluminación**: Preferir imágenes bien iluminadas
4. **Composición**: Evitar elementos distractores
5. **Autenticidad**: Buscar imágenes que parezcan reales

## Proceso de Optimización

1. Descargar imagen original
2. Redimensionar al tamaño adecuado
3. Optimizar compresión (80-90%)
4. Renombrar con nombre descriptivo
5. Añadir a carpeta /images/
6. Actualizar alt text en HTML
